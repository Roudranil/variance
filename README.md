# Variance

Personal expense tracker for Android. Local-first, double-entry bookkeeping under the hood, Material You UI.

## What it is

Variance tracks income, expenses, and transfers across multiple accounts. Internally it runs double-entry bookkeeping (DEB) as the financial engine — but the UI exposes nothing of that: no debits, no credits, just plain transaction types.

## Why it exists

No existing Android app combines all three of:
- local/offline storage (no cloud required, ever)
- double-entry bookkeeping as the financial model
- Material Design 3 (Material You) UI

## Platform

- Android only
- Minimum API 31 (Android 12)
- Offline-first — zero internet required for any v1 feature

## Tech stack

- Flutter / Dart
- Material Design 3
